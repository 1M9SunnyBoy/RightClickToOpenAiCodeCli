==========================================================
               安装前必看（Read Before Installing）
         Right-Click AI Code —— 右键打开 AI 编程 CLI
==========================================================

在安装之前，请花两分钟阅读下面的说明。
本工具会在你的系统里写入右键菜单，并判断你是否已经安装了相应的
AI 编程 CLI。全部看完再动手，可以避免装到一半才发现问题。


---------------- 1. 这个工具是做什么的 ----------------

给 Windows 的文件夹右键菜单添加入口，让你在任意文件夹里一键打开：

  - Claude Code
  - Codex
  - OpenCode

用法：在文件夹上（或在文件夹空白处）点右键，就能看到
“在此处打开 Claude Code / Codex / OpenCode”，点击后在当前目录启动对应的
CLI，并自动检测该 CLI 是否已安装。


---------------- 2. 安装前你需要确认的五件事 ----------------

【第 1 件】系统要求
  - Windows 10 或 Windows 11
  - 必须用「管理员权限」运行安装，因为要改注册表

【第 2 件】你必须先装好至少一个 AI 编程 CLI
  本工具本身不包含这些 CLI，它只是一个“启动器”。你需要先用 npm 装好：

    Claude Code： npm install -g @anthropic-ai/claude-code
    Codex：       npm install -g @openai/codex
    OpenCode：    npm install -g opencode-ai

  注意：
  - 上面这些都要用 npm 装，所以你得先装好 Node.js。
  - 安装器会检测“已经在 PATH 里”的 CLI。没装/不在 PATH 里的，
    在工具选择器里会置灰、无法勾选。
  - 如果三个 CLI 一个都没检测到，安装器会报错并退出。

【第 3 件】它会修改你的注册表
  安装器会在下面两个位置写入右键菜单项：
    HKEY_CLASSES_ROOT\Directory\Background\shell
    HKEY_CLASSES_ROOT\Directory\shell
  也就是“在文件夹空白处右键”和“在文件夹上右键”都会出现菜单项。
  （对文件右键不会出现，这是正常的。）

【第 4 件】它安装到哪个位置 —— 这一点很重要
  安装时，它只会把“运行时脚本 + 三个图标”复制到一个固定位置：
    C:\ProgramData\RightClickToOpenAiCode
  注册表也只会指向这个固定位置。所以：

  - 安装完成后，你可以随便移动、改名、删除这个源码文件夹，
    已经装好的右键菜单完全不受影响。
  - 如果你改了 RightClickToOpenAiCode.ps1，重新运行一次
    install.bat 即可把新副本刷新过去。
  - 卸载时只会删除上面那个 ProgramData 目录，绝不会碰源码文件夹。

【第 5 件】它“不会”安装什么
  install.ps1、i18n.ps1、*.bat 这些文件只留在源码文件夹里，
  不会被复制到硬盘，也无法单独运行。


---------------- 3. 安装步骤 ----------------

1. 右键点击 install.bat → 选择「以管理员身份运行」
2. 出现语言选择器：选一个界面语言
   （推荐选系统语言，会预选好），按回车确认
3. 出现工具选择器：勾选你想加入右键菜单的 AI CLI
   （只有已安装的才能勾选），按回车确认
4. 完成！对应的右键菜单入口已生效


---------------- 4. 卸载 ----------------

1. 右键点击 uninstall.bat → 选择「以管理员身份运行」
2. 右键菜单项和已安装到 ProgramData 的文件会一并移除


---------------- 5. 常见问题（FAQ） ----------------

Q1. 右键菜单没出现？
  - 确认你是用「以管理员身份运行」执行的 install.bat。
  - 确认你是在“文件夹”或其“空白处”右键，而不是在某个“文件”上右键。
  - 修改过脚本后没生效？重新运行一次 install.bat 刷新副本即可。

Q2. 某些 CLI 是置灰的，勾不了？
  - 说明它没有被安装，或者没有出现在 PATH 里。装好并加入 PATH 后，
    重新安装即可选中。

Q3. 界面文字乱码？
  - 源码文件夹里的脚本（.ps1）必须保持“UTF-8 with BOM”编码，
    否则中文/日文/韩文会被 PowerShell 5.1 读成 ANSI 而乱码。
  - 本说明文档也是 UTF-8 编码，请用支持 UTF-8 的编辑器打开。

Q4. 安装后想换语言，或者换要启用哪些 CLI？
  - 重新运行 install.bat 即可重选。选择会保存到
    C:\ProgramData\RightClickToOpenAiCode\language.txt 和
    tools.txt，下次安装会自动预选你上次的选择。

Q5. 双击 install.bat 一闪而过 / 直接退出？
  - 请改用“右键 → 以管理员身份运行”，不要直接双击。
  - 若仍然异常，可在命令行手动执行：
      powershell.exe -NoProfile -ExecutionPolicy Bypass -File "install.ps1"
